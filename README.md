# bunyaitter
bunyaitterは、TNTSuperManが制作している[Nyaitter/Server](https://github.com/Nyaitter/Server)の**非公式による**Bun向け実装です。

## ライセンス
設計や.env.example等は[Nyaitter/Server](https://github.com/Nyaitter/Server)を参考に作っています。
Nyaitter/Serverは[MITライセンス](https://github.com/Nyaitter/Server/blob/main/LICENSE)で提供されます。

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.4.0. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
